Prerequisite courses

One of the following, completed before the first class meeting:

  • CSS 142 Computer Programming I (UW Bothell)
  • CSE 122 Introduction to Computer Programming II (UW Seattle)
  • CSE 142 Computer Programming I (UW Seattle)

If you have already taken CSS 143 Computer Programming II, talk to the instructor in the first week: the two courses overlap.

What the course assumes

The course starts from structured programming as taught in a first programming course. You should be able to read a short program in the language you learned and say what it prints, and write one of the same size without help.

TopicYou can
Variables and typesDeclare and assign integers, floating-point numbers, Booleans and strings; say what type an expression has
ExpressionsEvaluate arithmetic with integer division and remainder; join strings and numbers
BranchingTrace if, else if and else, and tell a chain from a sequence of separate tests
Boolean expressionsEvaluate comparisons combined with and, or and not
LoopsTrace for and while loops, including nested ones, and count how many times a body runs
MethodsWrite a method with parameters and a return value; say what a call does to the caller's variables
ArraysIndex a one-dimensional array, loop over it without leaving its bounds, and say when two variables name the same array
StringsTake a length and a substring; build a string in a loop
Text filesRead values from a text file and write results to one
DebuggingRead an error message, find the line it names, and add print statements to test a guess

What the course does not assume

  • Python. The course is taught in Python and introduces it from the first line. The prerequisite courses use Java.
  • Classes and objects. Objects are introduced in week 6 and classes in week 9.
  • Statistics. Mean, standard deviation and correlation are defined when they are first used.
  • File systems. Paths, directories and managing files from a program are covered in weeks 7 to 9.

Java and Python differ in a few ways that matter from the first week:

JavaPython
TypesDeclared; a variable keeps its typeTaken from the value; a variable can be given a value of another type
BlocksBraces; indentation is for the readerIndentation is the block
Running codeCompile the program, then run itRun a file, or type one line at a time into the interpreter
NamescamelCasesnake_case
Program shapeEverything is inside a classA file of statements and functions is a complete program

Self-check quiz

Twelve questions on the topics above, in Java. Work each one on paper before choosing; do not run the code. The quiz is not graded and nothing you enter leaves this page.

Reading your score

6 or fewerReview all of the topics above, then take the quiz again. If the score does not change, talk to the instructor before the end of the first week.
